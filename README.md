# PixelPeel — AI-Based Onion Quality Assessment and Grading

A browser-based working prototype inspired by the uploaded reference video for SIH 2026 Problem Statement 26031.

## Prototype flow
Capture/upload onion batch → AI scanning animation → defect detection boxes → quality classification → Grade A / URS percentages → digital quality report.

## Run
Open `index.html` in a browser. No installation is required.

## Notes
The current prototype uses simulated AI results for the UI/demo. It is structured so a real YOLO/OpenCV/FastAPI inference backend can be connected later.
